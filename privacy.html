개인정보처리방침

시행일: 2026년 11월 2일 · 운영자: Oh kyoungmin

쉬는사이는 회원가입 없이 기기에서 쉬는 시간을 기록하는 앱입니다. 앱이 처리하는 정보와 이용자가 직접 선택하는 백업·문의 기능을 안내합니다.

기기 저장센서외부 전송보관과 삭제웹사이트문의

1. 기기에 저장하는 정보

쉬는 시간과 집중 기록, 잎의 생성·수집·사용 내역, 꾸미기 보유·선택·배치, 그림체·움직임·풍경 설정을 기기에 보관합니다. 별도 회원가입, 앱 운영 서버로의 자동 기록 전송, 자동 서버 동기화 기능은 없습니다.

2. 기기 센서

앱이 전경에 있는 동안 가속도와 Android 기기에서 제공되는 근접 센서를 이용해 휴대폰 상태를 확인합니다. 센서 값은 판별을 위해 기기에서 처리하며 앱 운영 서버에 전송하지 않습니다. 카메라·마이크·정밀 위치·연락처를 사용하지 않습니다.

3. 광고·분석·백업·문의

광고, 행동 추적, 외부 사용 분석 SDK를 사용하지 않으며 앱 데이터를 판매하거나 제3자에게 자동 전송하지 않습니다.

이용자가 백업 내보내기를 선택하면 기기의 진행 내용과 설정을 담은 JSON 파일을 만들고 운영체제의 파일 저장·공유 기능을 엽니다. 파일을 보낼 대상은 이용자가 직접 선택합니다. 해당 서비스의 처리는 그 서비스의 정책을 따릅니다.

지원 이메일로 직접 문의하면 발신 이메일 주소와 문의 내용이 이메일 서비스에 전송됩니다. 문의로 전달된 내용은 문의 확인과 답변을 위해 사용합니다. 본 웹사이트에는 개인정보를 수집하는 문의 양식이 없습니다.

4. 보관과 삭제

기기의 진행 내용은 이용자가 삭제하거나 앱 저장공간이 제거될 때까지 남습니다. 앱 삭제 또는 운영체제의 저장공간 관리로 앱 데이터를 삭제할 수 있습니다. 외부에 저장한 백업 파일은 해당 위치에서 별도로 삭제해야 합니다. 별도 계정이 없으므로 계정 탈퇴 절차도 없습니다.

기기 설정에 따른 운영체제의 백업·기기 이전 기능은 앱 자체의 서버 동기화와 별개로 동작할 수 있습니다. 앱 삭제나 기기 변경 전에 필요한 백업 파일은 별도로 보관해 주세요.

5. 공식 웹사이트

공식 웹사이트는 GitHub Pages로 제공되는 정적 소개·지원 페이지입니다. 자체 광고·분석 도구·로그인·쿠키 저장 기능을 사용하지 않습니다. 호스팅 제공자는 웹 요청 처리 과정에서 기본 접속 정보를 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보처리방침을 참고해 주세요.

6. 방침의 변경

앱의 정보 처리 방식이 바뀌면 이 페이지의 내용과 시행일을 갱신합니다. 중요한 변경은 앱 또는 공식 웹사이트에서 안내합니다.
