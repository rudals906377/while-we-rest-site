시작하는 방법

  1. 초원을 켜 두고 폰을 평평한 곳에 내려놓아요.
  2. 30초 안정 확인 뒤부터 쉬는 시간을 기록해요.
  3. 돌아오면 바닥의 잎을 손으로 쓸어 바구니에 모아요.
  4. 꾸미기에서 원하는 항목을 미리 보고 확정해요.
화면 잠금·다른 앱 사용·백그라운드 구간에는 집중 시간과 잎을 적립하지 않아요. 앱은 다른 앱의 사용 내역을 읽지 않아요.

자주 묻는 질문

내려놓았는데도 시간이 쌓이지 않아요.

앱이 앞에 보이는지, 휴대폰이 평평한 곳에 안정적으로 놓였는지 확인해 주세요. 안정 확인에는 30초가 필요해요. 기기를 움직이거나 앱을 조작하면 잠시 멈춰요. 센서가 확인되지 않으면 시간을 임의로 적립하지 않아요.

집중을 일시정지하거나 마치고 싶어요.

집중 화면에서 일시정지하고 다시 이어갈 수 있어요. 마치기를 선택하면 확인 후 종료해요. 앱을 다시 켰다고 집중이 몰래 시작되지는 않아요.

꾸미기는 선택하자마자 구매되나요?

선택하면 먼저 초원에 미리 보여요. 확정을 눌러야 최종 적용하며, 취소하면 이전 선택으로 돌아가요. 구매할 잎이 부족하면 확정할 수 없어요.

동물과 의자를 옮기거나 반전하고 싶어요.

설정의 ‘배치하기’에서 동물·의자·나무를 선택하고 위치를 바꿔요. 동물과 의자는 좌우 반전도 가능해요. 저장 전에는 취소해서 돌아갈 수 있어요.

기록을 백업하거나 복원하고 싶어요.

설정 → 데이터와 백업에서 파일을 내보내고 복원할 내용을 먼저 확인할 수 있어요. 복원은 기기의 진행 내용을 바꾸므로 현재 내용을 먼저 내보내 두는 것이 좋아요. 자동 클라우드 동기화는 없어요.

움직임이 불편하거나 기기가 뜨거워요.

설정의 ‘그림체와 움직임’에서 움직임 줄이기를 켤 수 있어요. 화면 밝기와 기기 절전 설정도 확인해 주세요. 문제가 계속되면 사용 환경을 이메일로 알려주세요.

개인정보 안내

진행 기록과 설정은 기기에 보관해요. 센서 값을 앱 운영 서버로 보내지 않아요. 자세한 내용은 개인정보처리방침에서 확인해 주세요.
