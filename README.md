# 쉬는사이 공식 사이트

기존 앱 자산과 실제 실행 화면을 사용한 정적 공식 사이트입니다.

- 홈: `index.html`
- 지원: `support.html`
- 개인정보처리방침: `privacy.html`
- 라이선스: `licenses.html`
- 출시 상태: `release.json` (스토어 공개 URL 확인 전에는 null 유지)

로컬 확인: `python3 -m http.server 4188 --bind 127.0.0.1 --directory website`

공개 문의 주소는 Google Play Console의 공개 개발자 프로필에서 인증된 주소를 확인해 사용했습니다. 로그인 이메일만으로 추정하지 않았습니다. 앱 원본 코드는 이 사이트 저장소에 포함하지 않습니다.
